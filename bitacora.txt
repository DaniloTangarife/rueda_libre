¿Qué significa 304 Not Modified?
Significa que la página no ha cambiado y el navegador
puede utilizar la versión que tiene guardada.

Es el esqueleto de la página y organiza su contenido.

JavaScript:

MINIRETO 2 - PÁGINA DE INICIO

¿Qué hice?
Organizar la página principal de Rueda Libre
utilizando etiquetas básicas de HTML.

1. Agregar un título principal h1 con el nombre
   Rueda Libre.

2. Organizar el contenido con h2 y h3 para
   los títulos y subtítulos.

3. Utilizar párrafos con la etiqueta p.

4. Utilizar strong para resaltar información
   importante y em para dar énfasis a algunas palabras.

5. Crear una lista ul con tres beneficios
   de alquilar bicicletas.

6. Crear una lista ol con los cuatro pasos
   para alquilar una bicicleta.

7. Agregar tres imágenes desde la carpeta img,
   utilizando src, alt y width.

8. Agregar tres tipos de enlaces:
   - Enlace interno a Encuéntranos.
   - Enlace externo a Google Maps.
   - Enlace para enviar un correo electrónico.

9. Utilizar target="_blank" para abrir
   Google Maps en otra pestaña.

¿Qué aprendi?
Aprendi a organizar una página con HTML,
agregar imágenes, crear listas y utilizar enlaces.

Todavia no utilizo CSS ni JavaScript porque estamos
trabajando solamente con HTML básico.

MINIRETO 3 - TARIFAS Y RUTAS

¿Qué hice?
Creé una página llamada tarifas.html dentro
de una carpeta llamada paginas para mostrar
los precios de las bicicletas y los recorridos.

1. Creé la carpeta paginas y dentro de ella
   agregué el archivo tarifas.html.

2. Agregué un título y una descripción
   para identificar la nueva página.

3. Creé una tabla con los precios de alquiler
   de las bicicletas urbanas, de montaña
   y eléctricas.

4. Creé otra tabla con los recorridos guiados,
   sus distancias, duración, nivel y precio.

5. Utilicé table para crear las tablas,
   caption para sus títulos, thead para
   los encabezados y tbody para los datos.

6. Utilicé tr para las filas, th para los
   encabezados y td para los datos.

7. Utilicé scope="col" para identificar
   los encabezados de columnas y
   scope="row" para los encabezados de filas.

8. Agregué la información sobre el casco,
   el candado y los horarios de salida.

9. Creé una lista ul con los elementos
   que debo llevar a los recorridos.

10. Agregué el logo utilizando ../img/logo.jpg
    porque la página está dentro de otra carpeta.

11. Conecté index.html con tarifas.html
    utilizando enlaces con rutas relativas.

12. Agregué un enlace desde los recorridos
    guiados de inicio hacia la tabla de recorridos
    utilizando #recorridos.

¿Qué aprendí?
Aprendí a crear tablas en HTML y organizar
la información en filas y columnas.

También aprendí a utilizar rutas relativas
para conectar archivos que están en
diferentes carpetas.

Comprendí que ../ sirve para subir
un nivel de carpeta y que #id permite
ir directamente a una sección.
