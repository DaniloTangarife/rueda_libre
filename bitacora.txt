¿Qué significa 304 Not Modified?
Significa que la página no ha cambiado y el navegador
puede utilizar la versión que tiene guardada.

¿QUÉ FUNCIÓN CUMPLEN HTML, CSS Y JAVASCRIPT?

HTML:
Es el esqueleto de la página y organiza su contenido.

CSS:
Sirve para darle estilos, colores y diseño a la página.

JavaScript:
Sirve para agregar funciones e interactividad a la página.


MINIRETO 2 - PÁGINA DE INICIO

¿Qué hice?
Organizar la página principal de Rueda Libre
utilizando etiquetas básicas de HTML.

1. Agregar un título principal h1 con el nombre
   Rueda Libre.

2. Organizar el contenido con h2 y h3 para
   los títulos y subtítulos.

3. Utilizar párrafos con la etiqueta p.

4. Utilizar strong para resaltar información
   importante y em para dar énfasis a algunas palabras.

5. Crear una lista ul con tres beneficios
   de alquilar bicicletas.

6. Crear una lista ol con los cuatro pasos
   para alquilar una bicicleta.

7. Agregar tres imágenes desde la carpeta img,
   utilizando src, alt y width.

8. Agregar tres tipos de enlaces:
   - Enlace interno a Encuéntranos.
   - Enlace externo a Google Maps.
   - Enlace para enviar un correo electrónico.

9. Utilizar target="_blank" para abrir
   Google Maps en otra pestaña.

¿Qué aprendi?
Aprendi a organizar una página con HTML,
agregar imágenes, crear listas y utilizar enlaces.

Todavia no utilizo CSS ni JavaScript porque estamos
trabajando solamente con HTML básico.
