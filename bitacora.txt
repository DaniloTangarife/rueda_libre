# BITÁCORA - RUEDA LIBRE

## MINIRETO 1 - PETICIONES HTTP

**Datos de la petición:**

- URL: http://127.0.0.1:5500/index.html
- Protocolo: HTTP/1.1
- Host: 127.0.0.1
- Puerto: 5500
- Ruta: /index.html
- Método: GET
- Estado: 304 Not Modified

**¿Qué significa 304 Not Modified?**

Significa que la página no ha cambiado y el navegador puede utilizar la versión guardada.

**Ruta que no existe:**

- Ruta: /index.html/promociones.html
- Error: ENOTDIR: not a directory
- Estado: 500 Internal Server Error

**¿Qué significa?**

El servidor intentó buscar una página dentro de index.html como si fuera una carpeta.

**¿Qué función cumplen HTML, CSS y JavaScript?**

- HTML: Organiza la estructura y el contenido.
- CSS: Da estilos y diseño a la página.
- JavaScript: Agrega funciones e interactividad.

## MINIRETO 2 - PÁGINA DE INICIO

**¿Qué hice?**

Organicé la página de inicio utilizando HTML básico.

- Utilicé h1, h2 y h3 para organizar los títulos.
- Agregué párrafos con p, strong y em.
- Creé una lista ul con tres beneficios y una ol con cuatro pasos para alquilar.
- Agregué tres imágenes con src, alt y width.
- Agregué enlaces a Google Maps, al correo y a la sección Encuéntranos.

**¿Qué aprendí?**

Aprendí a organizar el contenido de una página utilizando encabezados, párrafos, listas, imágenes y enlaces.

## MINIRETO 3 - TARIFAS Y RUTAS

**¿Qué hice?**

Creé `paginas/tarifas.html` con dos tablas: una para los precios de alquiler y otra para los recorridos guiados.

- Utilicé table, caption, thead, tbody, tr, th, td y scope.
- Agregué los horarios, la información del casco y candado y una lista de qué llevar.
- Mostré el logo utilizando `../img/logo.jpg`.
- Conecté las páginas mediante rutas relativas y agregué un enlace directo a `#recorridos`.

**¿Qué aprendí?**

Aprendí a crear tablas y a conectar archivos de diferentes carpetas utilizando rutas relativas como `../`.

## MINIRETO 4 - RUEDA LIBRE V0.1

**¿Qué hice?**

Creé `paginas/reservas.html` y conecté las tres páginas mediante un menú de navegación.

- Agregué un menú con Inicio, Tarifas y rutas, y Reservas.
- Utilicé dl, dt y dd para mostrar los horarios de atención.
- Agregué el correo con mailto y un pie de página con el nombre, correo y año.
- Agregué enlaces «Reservar ahora» desde inicio y tarifas.

**Tabla de rutas relativas:**

| Origen | Destino | Ruta |
|---|---|---|
| index.html | Inicio | index.html |
| index.html | Tarifas | paginas/tarifas.html |
| index.html | Reservas | paginas/reservas.html |
| tarifas.html | Inicio | ../index.html |
| tarifas.html | Tarifas | tarifas.html |
| tarifas.html | Reservas | reservas.html |
| reservas.html | Inicio | ../index.html |
| reservas.html | Tarifas | tarifas.html |
| reservas.html | Reservas | reservas.html |

**Verificación en DevTools:**

Navegué entre las tres páginas utilizando el menú y comprobé en Network que no se presentaron errores 404.

**¿Qué aprendí?**

Aprendí a conectar varias páginas con un menú, utilizar rutas relativas y mostrar horarios con listas de definiciones.
